# Sound sources

Every file here is a trimmed, mono, 48 kbps MP3 cut from a recording released
under CC0 (public domain dedication). No attribution is required; it's listed
anyway so anyone can trace a file back to its original.

BigSoundBank files were cut from the original FLAC or WAV. Freesound files
were cut from the site's public 128 kbps preview of the CC0 sound, which needs
no login.
